# Print Agent Installation

Build from `nova-print-agent` with `npm install`, `npm run package`, and `npm run make`. On Windows the Squirrel maker outputs `Nova-Print-Agent-Setup.exe` under `nova-print-agent/out/make`.

After install, open Nova Print Agent, enter the ERP URL and pairing code generated by an ERP admin, refresh printers, and configure cashier/kitchen/bar printers in ERP settings.
