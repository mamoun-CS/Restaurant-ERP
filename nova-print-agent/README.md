# Nova Print Agent

Local Windows printing bridge for Sheikh Al Kar ERP.

## Development

```bash
npm install
npm run start
```

Pair the device from the settings window using an ERP URL and a short pairing code generated by an ERP admin.

## Packaging

```bash
npm run package
npm run make
```

Windows installer output is created under `out/make` as `Nova-Print-Agent-Setup.exe`.

## Security

The renderer uses `contextIsolation`, `nodeIntegration: false`, and a narrow preload bridge. Device tokens are stored separately with Electron `safeStorage` when available and are never written to the normal JSON config.
